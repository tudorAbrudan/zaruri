Scanează toate View-urile Swift din `zaruri/Views/` pentru elemente interactive fără `accessibilityLabel`.

Caută:
1. `Button { ... } label: { Image(systemName:` — iconițe fără label text
2. `.onTapGesture` pe elemente care nu au `.accessibilityLabel`
3. `NavigationLink` cu `Image` ca label fără text descriptiv
4. `Image(systemName:)` standalone interactiv

Pentru fiecare problemă găsită, afișează:
- Fișier + număr linie
- Codul problematic
- Sugestie concretă de fix (ex: `.accessibilityLabel("Aruncă zarurile")`)

La final, generează patch-urile (Edit) pentru primele 3 probleme critice găsite, adăugând `.accessibilityLabel()` corespunzător.
